Event Handler Implementation Methods

Two different event handling methods are used across the website:

  1. HTML Attribute Method (Method 1):
    • Visit Page: Reset button event (visit.js, line 48)
    • Information Page: Video ended event (information.js, line 142)
    • Apply Page: Zone click event (apply.js, line 89)
  2. JavaScript addEventListener Method (Method 2):
    • Visit Page: Form submit event (visit.js, line 50)
    • Information Page: Video error event (information.js, line 145)
    • Apply Page: Rank choice buttons (apply.js, line 432)
